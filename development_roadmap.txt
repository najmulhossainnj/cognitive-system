# COS Agentic Development Roadmap

## Overview

The Cognitive Operating System will be implemented through a sequence of structured development phases.

Each phase has:

- Goal
- Inputs
- Outputs
- Deliverables
- Acceptance Criteria
- Prompt Template

The coding agent should never skip phases.

---
